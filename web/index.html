Scope & fidelity

This is an independent educational software testbed, not flight-qualified software, a real mission digital twin, or a NASA-endorsed product. The orbit is illustrative; thermal, power, and attitude models are deliberately simplified. The watchdog is fault-injection logic, not a real-time operating system watchdog.

The current implementation uses a custom C++ core and vanilla web console. NASA F Prime, NASA Open MCT, FastAPI, PostgreSQL, WebSockets, physical hardware, and a public deployment are not implemented in this release. See the repository gap ledger before making application claims.

All controls, calculations, storage, and graphics run locally. No API keys, paid infrastructure, fonts, analytics, or remote assets are required.
